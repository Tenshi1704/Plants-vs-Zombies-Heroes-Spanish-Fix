Plants vs Zombies Heroes

Spanish Fix 🌿

Este proyecto proporciona un parche de traducción al español para el juego Plants vs Zombies Heroes, corrigiendo errores de idioma y textos sin traducir presentes en la versión original.

Características

  • Corrección de textos mal traducidos
  • Traducción completa al español
  • Compatibilidad con la versión original del juego
  • Proyecto de código abierto alojado en GitHub
