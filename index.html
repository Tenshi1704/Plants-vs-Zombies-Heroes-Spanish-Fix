Plants vs Zombies Heroes

Spanish Fix 🌿

Este proyecto proporciona un parche de traducción al español para Plants vs Zombies Heroes, corrigiendo etiquetas del juego, textos que no corresponden y errores que vienen en la traducción proporcionada por PoPCap.

Características

  • Corrección de textos desactualizados
  • Corrección de etiquetas
  • No interfiere con el modo multijugador
  • Proyecto de código abierto alojado en GitHub
